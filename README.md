# 🌾 Wheat Intelligence Platform — Ludhiana 2023-24

Satellite-based wheat monitoring using Sentinel-2 L2A imagery and machine learning.

## Project structure

```
wheat_ludhiana_app/
├── config.py                   Central config, paths, thresholds, real GEE stats
├── utils.py                    Raster I/O (rasterio or PIL fallback), stats helpers
├── feature_engineering.py      Spectral feature computation + target synthesis
├── ml_pipeline.py              Train RF / GBM / LR classifiers, save artefacts
├── explainability.py           Feature-importance + SHAP-style plots
├── main.py                     FastAPI REST backend (port 8000)
├── app.py                      Streamlit dashboard
├── app_driver.py               CLI pipeline runner
├── requirements.txt            Python dependencies
├── index.html                  React entry point
├── package.json                Node dependencies (React 18, Recharts, Leaflet)
├── tsconfig.json
├── vite.config.ts              Vite + /api proxy to FastAPI
├── src/
│   ├── main.tsx
│   ├── App.tsx                 Full tabbed React dashboard
│   ├── index.css               Tailwind base styles
│   ├── mockData.ts             Real GEE values as offline fallback
│   ├── cn.ts                   clsx + tailwind-merge utility
│   └── components/
│       └── WheatMap.tsx        Leaflet map with georaster TIF overlay
├── data/                       ← place GEE export files here (see data/README.txt)
├── outputs/                    ← auto-generated by pipeline
├── models/
└── reports/
```

## Quick start

### 1 — Add GEE data
Copy your exported files into `data/` (see `data/README.txt`).

### 2 — Python environment
```bash
pip install -r requirements.txt
```

### 3 — Run the ML pipeline
```bash
python app_driver.py
```
This runs feature engineering → model training → SHAP plots.  
Outputs are written to `outputs/`.

### 4a — Streamlit dashboard (self-contained)
```bash
streamlit run app.py
```

### 4b — React + FastAPI (full-stack)
Terminal 1 — API:
```bash
python main.py
```
Terminal 2 — Frontend:
```bash
npm install
npm run dev
```
Open http://localhost:5173

## Tech stack

- **Satellite data**: Google Earth Engine — Sentinel-2 L2A surface reflectance
- **ML**: scikit-learn (RandomForest, GradientBoosting, LogisticRegression)
- **API**: FastAPI + uvicorn
- **Dashboard**: Streamlit / React 18 + Vite + Recharts + react-leaflet
- **Raster I/O**: rasterio (preferred) / PIL (fallback)
